# Lead Capture & Qualification Workflow

Automatically captures website leads, scores them using AI-driven qualification criteria, logs them to Google Sheets, and triggers personalized follow-up emails — removing manual lead triage from the sales process.

**Tools used:** n8n, AI-based lead scoring, Google Sheets API, transactional email automation

**Workflow file:** `lead-capture-workflow.json`
